# 番茄字数统计反推

## 样本

- 读取番茄章节管理列表第 1–86 章的平台字数。
- 对同一批本地正文分别计算多种候选口径。
- 第 87 章尚未出现在平台章节列表，不纳入样本。

## 结果

旧口径为“去空白后的 UTF-16 单元数”：

- 平均绝对误差约 24.2 字。
- 中位绝对误差 21 字。
- 最大误差 107 字。
- 86 章均为本地估算偏高。

最接近平台的候选口径为：

1. 去除空白。
2. 连续 ASCII 英文字母和数字按一个词计算。
3. 忽略大多数非 ASCII 的 Unicode 符号和组合标记。
4. 其余汉字、标点和字符按一个计算。

该口径在 86 章样本中：

- 平均绝对误差约 8.6 字。
- 最大误差约 34 字。

## 使用原则

番茄没有公开这里的精确计数规则，因此本地结果仍标记为“估算”。列表校验继续保留原有宽容差，不用几字的差异判断发布失败。字数只作为“平台内容是否已经刷新”的辅助信号，正文一致性仍应以实际正文比较为准。

## 最终校验闭环

同步和发布不再依赖本地反推字数作最终判定：

1. 正文写入后读取番茄编辑器自己的“正文字数”。
2. 提交后等待章节列表字数与编辑器字数完全一致。
3. 如果列表长期未闭环，只重新打开异常章节，自动放弃旧编辑缓存并读取平台最新正文。
4. 平台标题、正文与本地规范化内容一致时判定成功，忽略字数差异。
5. 实际正文不一致时才判定失败，并生成最新 `diff.patch`。

本地字数估算只用于编辑器字数无法读取时的兜底判断和日志展示。
